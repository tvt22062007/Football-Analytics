# Football Analytics

A personal project for learning and applying football data analysis with Python.

## Project Goal

This project aims to analyze football player data and gradually develop my skills in:

- Python
- Pandas

- Data visualization
- Football analytics

## Day 1 - Pandas Basics

In Day 1, I practiced basic Pandas operations with football player data.

### What I learned

- Reading CSV files with Pandas
- Filtering data
- Sorting data
- Finding maximum values
- Calculating the mean
- Combining multiple conditions

### Examples

- Finding the oldest player
- Finding the top 3 players by assists
- Finding players under 25 with at least 10 goals
